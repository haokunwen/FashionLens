# FashionLens: Versatile Fashion Image Retrieval via Task-Adaptive Learning

This repository contains the official code and data annotations for the paper:

> **FashionLens: Versatile Fashion Image Retrieval via Task-Adaptive Learning**

---

## 📖 Overview

Fashion image retrieval is a cornerstone of modern e-commerce systems. A unified framework that supports diverse query formats and search intentions is highly desired in practice, yet existing approaches focus on narrow retrieval tasks and do not fully capture such diversity.

In this work, we aim to develop a unified framework capable of handling diverse realistic fashion retrieval scenarios, achieving truly versatile fashion image retrieval. 

## 📦 Repository Contents

This repository currently provides:

- ✅ **Source code** — model implementation, training and evaluation scripts.
- ✅ **Annotation files* — the metadata, splits, and task-level annotations used to construct the U-FIRE benchmark.

The following will be released after the paper is accepted:

- ⏳ Detailed source information and download instructions for each raw image dataset used in U-FIRE.
- ⏳ Pre-trained model checkpoints.
- ⏳ Step-by-step instructions for reproducing every reported task.

## ⚠️ Notice on Data and Copyright

**We do not own or redistribute any of the raw image data used in this work.**

The U-FIRE benchmark is built upon a collection of **publicly available, third-party fashion datasets**. The copyright of these raw images belongs to their **respective original authors and dataset providers**. We only release:

1. **Our own annotations and task-level metadata** (provided as JSON files in this repository), and
2. **Our code** for organizing, processing, and evaluating retrieval models on top of these datasets.

To respect the licenses and policies of the original data providers, the **exact list of source datasets, download links, and citation information will be made publicly available upon the paper's acceptance.** Users who wish to reproduce our experiments will need to obtain the raw images directly from the original sources, following the terms of use specified by each dataset owner.

If you are a rights holder of any data that you believe is improperly referenced in this repository, please contact us and we will address the issue promptly.
